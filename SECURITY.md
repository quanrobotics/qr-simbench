# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting), or
- email **security@quanrobotics.org**.

Include what is affected, how to reproduce it and the impact you see. We acknowledge reports within
3 working days and aim to publish a fix or mitigation within 30 days, crediting you if you wish.

## Supported versions

The latest released minor version receives security fixes.

## Scope

QR-SimBench runs simulations and local tools on your own machine. Scenario files, world files and plugins
can execute code (launch files, Python plugins): only run files you trust.
